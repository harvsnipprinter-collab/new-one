FIX FOR THE MISSING App / Engine BUILD ERROR

1. Extract this ZIP on your computer.
2. Open codemagic.yaml from this extracted folder.
3. Replace the contents of codemagic.yaml in GitHub with this entire file.
4. Commit the change to the branch Codemagic builds.
5. Start a new Codemagic build on that branch.

You only need to upload codemagic.yaml for this fix. It includes a fallback
source snapshot and restores it when the repository source folders are missing.
A complete source checkout takes priority, so future app edits can build normally.
For normal source development, upload App, Engine, Scripts and project.yml too.
Do not paste the ZIP itself into the YAML editor.

Validated here: YAML parsing, shell syntax, source restoration and source-byte
comparison. Xcode and iOS SDKs are unavailable in this Linux environment, so
an iOS archive has not been compiled here. The IPA still requires signing.
